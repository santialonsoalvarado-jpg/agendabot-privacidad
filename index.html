Política de privacidad de AgendaBot

Última actualización: 28 de octubre de 2026

1. Finalidad

AgendaBot es un proyecto escolar que busca ayudar a los estudiantes a recordar sus tareas, trabajos y fechas de entrega mediante mensajes automatizados por WhatsApp.

2. Datos utilizados

El proyecto podrá utilizar nombres, números de teléfono y datos relacionados con las tareas escolares, únicamente cuando sean necesarios para enviar recordatorios.

3. Uso de la información

La información se utilizará exclusivamente para el funcionamiento de AgendaBot y el envío de recordatorios académicos. No se venderán los datos personales.

4. Protección de datos

Se tomarán medidas razonables para proteger la información y limitar su acceso a las personas autorizadas para gestionar el proyecto.

5. Contacto

Para consultas sobre esta política de privacidad o el tratamiento de datos personales, puedes comunicarte con el responsable de AgendaBot a través del siguiente correo electrónico: santiagoalonso1901@gmail.com.

6. Solicitud de eliminación de datos

Los usuarios podrán solicitar la eliminación de sus datos personales escribiendo al correo electrónico de contacto indicado en esta política. La solicitud será revisada y atendida conforme a las obligaciones aplicables.
